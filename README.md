# Supplementary Data S1

**Adaptive ship path following in curved, confined waterways using yaw-moment feedforward from a nonuniform current field**

Yifan Li, Yixiong He, Kun Zhang, Wenlu Liu and Shuzhe Chen. Version 2026-11-21-r2.

[Download the complete dataset](Supplementary_Data_S1_2026-11-21-r2.zip) · [Browse the data and table index](S1/README.md) · [Citation metadata](CITATION.cff)

The archive contains simulation data from the Yingongzhou reach of the Yangtze River. It includes the steering-budget selection records, departure-phase and current-prior sensitivity tests, 25 paired ablation passages, and analytic current-field tests. See the table index for the inputs and comparisons associated with each display.

To check the data, extract the ZIP and run `python verify.py` with Python 3.10 or newer. From a Git checkout, run `python S1/verify.py`. Both commands run offline and use the Python standard library.

SHA-256 for the downloadable ZIP: `c2f404a61bab09dd6d58308fc32eadd16b11764b5d66737d96fddd32928561a2`.

The [first S1 release](https://github.com/tangrenshen/oe-/tree/s1-2026-11-21) contains the same simulation records and verification scripts. This release updates the dataset author list.

The [October 2026 snapshot](https://github.com/tangrenshen/oe-/tree/7052fd902f6e5c43c0935f22ccc4d16f55d6a87c) preserves the earlier model sources and simulation records. The original electronic navigational charts are subject to the provider’s redistribution terms.
